# 今刻 · ColorOS 语音日历

今刻 1.0 是面向 ColorOS／Android 的个人语音日历。核心交互是全局语音控制，主界面只保留“今日”和“关键”，仓库同时提供可点击 Web 预览与签名 Android APK。

## 当前可体验

- 今日时间轴、重复事务与完成勾选
- 日／月临时检视：日视图本身包含可切换的一周；月视图可切换月份，点击任意日期会留在月视图并在下方查看当天事项
- “今刻助手”语音／文本入口、结构化意图路由与执行前确认；未知操作绝不会兜底创建任务
- 语音草稿确认卡可直接修改名称、类型、时间、重复、提醒、截止时间和备注
- 语音创建、删除、批量清除、勾选、取消勾选、批量完成和修改任务
- 语音设置 DDL、按天／周／月延期，以及修改名称、时间、重复、提醒和备注
- 语音打开今日、关键、历史、月报、年报、设置，切换日期／日周月检视与暗色／亮色／跟随系统
- 语音查询日常、DDL 与无 DDL 事项数量；找不到唯一目标时要求补充，不猜测、不执行
- 同一预览窗口同时展示 Find N3 外屏 430 × 956 与展开全面屏 860 × 956，两边共享同一状态并可交叉操作验证
- 双预览会实时同步页面、日期、勾选、主题、编辑字段、语音确认草稿和日期档案翻页，不只同步保存结果
- 展开屏以物理折痕为严格中线等分：今日页左侧日期／检视／DDL、右侧日常事项；关键页左侧有 DDL、右侧无 DDL，底部导航保持原位
- 关键事项续期天数可编辑并默认 7 天；顶部铃铛可点击进入“通知与权限”
- 日／月选择面板与更多菜单不显示“临时检视”“更多”等装饰标题，打开后直接呈现操作项
- 使用真实安全区，不绘制假的系统状态栏或黑色操作提示
- 长列表滚动严格裁切在屏幕内，顶部和底部以透明度渐变隐藏
- 每日完成记录以“任务 ID＋日期”唯一保存，反复勾选不会生成重复统计
- 周日期条可直接切换：今天固定红色，选中的其他日期使用白色高亮；日期标题、进度和勾选记录同步切换
- 周历小点和月历红点只表示真实存在的日常任务或当天截止 DDL，删除任务后即时同步消失
- 每个日期标题都显示真实的中国历法标记：节日／节气优先，普通日期回退到农历与七十二候，不虚构“纪念日”
- 日期旁的无底无边透明微型按钮打开“今天是什么日子”，可切换中国、全球节日、历史事件和人物纪念；人物条目内部标注诞辰／逝世
- 全球日期档案联网读取 Wikimedia On This Day 中文数据，按当前分类懒加载并缓存至本机；普通屏与展开屏复用同一个请求，断网仍保留中国历法标记
- 日常事务单击只勾选或取消完成；向左滑动后才显示圆弧分离的“编辑 / 删除”操作
- 删除日常事务可仅停止所选日期起的未来安排并保留此前统计，也可连同全部历史记录一起清除；新任务只从创建当天起生效
- 所有未完成且有 DDL 的关键事项同时显示在每日页面，剩余／逾期天数按当前所选日期计算
- 关键事项点击卡片即可编辑名称、期限、提醒、完成度和备注
- 编辑面板直接呈现字段，不显示“编辑日常事务”等标题或辅助介绍文案
- 语音确认页不显示“已经听懂”标题，直接呈现可编辑字段或待确认操作
- 默认暗色外观；“更多”中可切换暗色、跟随系统或亮色，选择会在本机持久保存
- 中文口语归一化会清除“点钟”“的”“啊”“吧”等非任务内容；普通日期安排不再自动升级为 DDL
- 任务标题使用分层语义提取：先分离时间状语、重复、期限、持续时长、意图词和助词，再保留核心动作与对象关键词
- 明确月日（支持“九月十五号”等中文数字）会自动识别为关键事项并从名称中剥离；“明天去养老院”仍是一项日常安排
- 关键页铃铛打开 DDL 提醒设置；默认汇总时间、倍数节点与最后连续提醒天数均可编辑并持久化。当天没有命中任务时不发送通知，但全部 DDL 仍正常显示在今日与关键列表
- DDL 支持具体时刻：未设置时使用阶段汇总提醒；具体时刻不晚于默认时间时只在该时刻提醒，晚于默认时间时保留阶段汇总并在截止日具体时刻再次提醒
- 有 DDL / 无 DDL 的关键事项
- DDL 当天“续期 30 天”与“已完成”处理
- 完成后进入历史记录
- 月度完成率排名和年度完成率排名
- 年度提前完成 DDL 的 Top 10 排名
- Android 原生 DDL 通知调度、开机／时区变化后重建提醒与通知权限请求
- 设置上方提供“版本更新”，连接 GitHub Releases；发现新版后可在应用内下载，并交给 Android 系统安装器确认安装
- reduced-motion 动效降级


预览地址：`http://127.0.0.1:43190`

`4173` 是 House Memory Studio 的 Cloudflare Tunnel 回源端口，今刻禁止使用 `4173` 或依赖自动选端口；项目脚本固定使用仅本机可访问的 `43190`，避免测试服再次抢占正式域名回源。

浏览器首次使用语音时需要允许麦克风权限。没有权限时可以点“使用示例”走完完整流程。

可以尝试：“我想在九月十五号下午三点的时候去考驾照”、“提醒我明天早上九点给妈妈打电话”、“每天晚上十点写一下日志吧”、“把健身改到晚上八点”或“清除所有安排”。前三句会分别提取为“考驾照”“给妈妈打电话”“写日志”，日期、时刻、重复和持续时间进入各自字段，不污染名称。删除、批量清除、完成和修改会先显示明确的操作与目标；“清除所有安排”只清除未完成事项并保留历史记录。

## Android 1.0

- 包名：`com.junyingjun.jinke`
- 最低 Android 9（API 28），目标 Android 16（API 36）
- 构建：`scripts/build-android.ps1`
- Release APK：GitHub Releases 中的 `jinke-coloros-v1.0.16.apk`
- 更新源：`https://api.github.com/repos/Junyingjun/jinke-coloros-calendar/releases/latest`

首次从 GitHub 更新时，Android 会要求授予“安装未知应用”权限；下载完成后仍由系统安装器显示最终确认，这是 Android 对侧载更新的安全要求。发布签名保存在本机工作区之外，不进入 Git 仓库；后续版本必须沿用同一签名才能覆盖安装。

## 文件结构

- `styles.css`：颜色、排版、间距、动效与响应式 token
- `data.jsx`：任务、历史和复盘种子数据
- `primitives.jsx`：图标、设备框、列表行、底部导航与浮层
- `screens.jsx`：今日、关键、语音、历史、复盘与权限界面
- `app.jsx`：路由、状态、语音识别、意图解析、目标匹配和任务操作
- `tests/voice-router.test.mjs`：助手意图、参数提取与“未知操作不创建”回归测试
- `PRODUCT.md` / `DESIGN.md`：产品与设计系统
- `.impeccable/design.json`：机器可读设计扩展
- `assets/`：应用图标和透明标记
- `android/`：原生 WebView、DDL AlarmManager、通知、语音识别与 GitHub APK 更新桥接
- `scripts/`：签名构建与线上 Release 验证脚本

## 语音技术方向

正式 Android 版本优先采用 [k2-fsa/sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)，理由是它提供 Android、Kotlin、arm64、流式识别以及中文 / 中英模型。备选研究包括 [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp)、[alphacep/vosk-api](https://github.com/alphacep/vosk-api) 和 [modelscope/FunASR](https://github.com/modelscope/FunASR)。

## 当前边界

1.0 内置 Vosk 中文离线识别模型，并支持调用当前输入法继续修正文稿。通用 Android 通知和更新链路已经原生化，但 ColorOS 的自启动／电池“不限制”策略无法由标准模拟器完整复现，仍需在 OPPO 真机首次安装后授权并验收。
